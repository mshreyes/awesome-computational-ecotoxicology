# Contribution Guidelines

Contributions are welcome. Before submitting a resource, please check that:

1. It has a clear application in ecotoxicology or ecological risk assessment.
2. It is publicly accessible, or its access conditions are clearly documented.
3. A stable official URL or repository is available.
4. It is not a duplicate or superseded resource.
5. The description is factual and concise.
6. It is placed in the most specific applicable category and listed only once.

For software and datasets, please provide the official project repository or landing page whenever possible.

Please also read the Inclusion Criteria in the [README](README.md#inclusion-criteria).
